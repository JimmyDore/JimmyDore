## By day, at Vianova

[Vianova](https://vianova.io) gives cities and mobility operators, from Munich to Malmö, dashboards, maps and an API on their mobility data. I joined in 2021 and I'm now Lead Backend Engineer. I built the query API behind the dashboards, and the Claude-powered layer on top of it that turns plain-language questions into queries. That code is private, so [the case file](https://jimmydore.fr/work/vianova) tells the story.
